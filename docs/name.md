# The name

## Where it came from

"CoCo Zero" began as the name of one project: a CoCo on a board the size of a
Raspberry Pi Zero. It became the name for the idea once the same board ran a
CoCo 3 too, and this standard now says what it means.

## Using it

- **If it meets the standard, it is a CoCo Zero.** Anything that meets every
  requirement in the one-page spec,
  [`spec/coco-zero-spec.pdf`](../spec/coco-zero-spec.pdf), may be called a
  CoCo Zero, in its name, on its box, or in a post about it. No permission,
  fee or review is needed. The standard is the one published at
  [github.com/ugufru/coco-zero](https://github.com/ugufru/coco-zero).
- **If it does not, say what it is instead.** There is no "CoCo Zero
  compatible" or other half-way name.
- **There is no logo.** The standard has no logo, badge or branding. The
  name is all there is.
- **Add it to the list.** Known CoCo Zeros are listed in
  [`implementations/`](../implementations/README.md).

## Other people's names

A CoCo Zero is not a Tandy or a Raspberry Pi product, and nothing about it
should suggest that it is.

- **Tandy and Color Computer** belong to their owners. Color BASIC and its
  successors are © Microsoft, Tandy and Microware, which is why no CoCo Zero
  ships with ROMs.
- **Raspberry Pi** is a trademark of Raspberry Pi Ltd. Say a board is "the size
  of a Raspberry Pi Zero" to describe it, not to claim a connection.
- **HDMI** names the connector and the cable, and nothing else. A CoCo Zero's
  signal is DVI with embedded sound.
- **XRoar** is Ciaran Anscomb's emulator. A CoCo Zero built on it should say so.

This page is guidance, not legal advice.
