# Versions and changes

Current version: **1.0**

## Numbering

The standard is numbered MAJOR.MINOR.

- **Major:** a change that could stop an existing CoCo Zero meeting the
  standard, such as a new requirement or a tighter one.
- **Minor:** any other change to a requirement, such as a looser one or a
  clearer wording.
- **None:** a change outside [`spec/`](../spec/), or a fix that leaves every
  requirement as it was.

The version applies to the whole of `spec/`. The one-page PDF carries it.

## Proposing a change

Open an issue that says what should change and why, then a pull request. See
[CONTRIBUTING.md](../CONTRIBUTING.md).
