# CoCo Zero form factor

Status: **accepted** (CZ-6)

A CoCo Zero is built on a board of the Raspberry Pi Zero size.

## Source

Raspberry Pi mechanical drawing *Raspberry Pi Zero*, ref RPI-ZERO-V1_2,
dated 23/09/2015:
<https://datasheets.raspberrypi.com/rpizero/raspberry-pi-zero-mechanical-drawing.pdf>

The *Raspberry Pi Zero 2 W* drawing gives the same values:
<https://datasheets.raspberrypi.com/rpizero2/raspberry-pi-zero-2-w-mechanical-drawing.pdf>

"Raspberry Pi" is a trademark of Raspberry Pi Ltd.

## Requirements

All dimensions in millimetres. The origin is one corner of the board, with X
along the 65 mm edge and Y along the 30 mm edge.

| Feature | Value |
|---|---|
| Board outline | 65 x 30 |
| Corner radius | 3.0 |
| Mounting holes | 4, for M2.5, drilled 2.75 +/- 0.05 |
| Hole centres | (3.5, 3.5), (61.5, 3.5), (3.5, 26.5), (61.5, 26.5) |
