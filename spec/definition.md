# What is a CoCo Zero

Status: **accepted** (CZ-3)

A CoCo Zero is a Tandy Color Computer emulator on a board the size of a
Raspberry Pi Zero. Switch it on and BASIC is there, with no operating system
in between. It is at least a 128K CoCo 3. It plugs into an ordinary TV with a
mini HDMI cable, takes a USB keyboard and gamepad, and keeps its disks and
programs on a microSD card. Anyone can build one, on any board of that size,
and every one fits the same case.

## What makes one

- **The size.** A board of the Raspberry Pi Zero outline, with the same four
  mounting holes. See [Form factor](form-factor.md).
- **Zero operating system.** One layer of software between you and the
  machine. See [Zero operating system](zero-os.md).
- **A CoCo.** At least a 128K CoCo 3, and a 64K CoCo 1 or 2 if it offers one.
  See [Machines](machines.md).
- **Modern connections.** Mini HDMI, two USB-C ports and microSD, with a
  640 x 480 picture at 60 Hz and its sound on one cable. See
  [Features](features.md).
- **Real time.** Double speed with no dropped frames and no gaps in the
  sound.
- **Quiet.** No fan.
- **Open.** The firmware is open source.

## What it is not

- **Not a Color Computer.** It emulates one. It needs ROMs from hardware you
  own.
- **Not one board.** The reference CoCo Zero is one implementation of many.
- **Not an app.** An emulator on a desktop computer runs on an operating
  system. A CoCo Zero is a machine of its own.
- **Not a blueprint.** The standard fixes the outside and leaves the rest to
  the builder.
