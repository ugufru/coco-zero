# CoCo Zero zero operating system

Status: **accepted** (CZ-18, CZ-26)

## Requirements

- The firmware runs on the bare hardware, with no operating system.
- Libraries are not operating systems. A library the firmware is built on is
  allowed.
- Alongside the emulated CoCo there is one configuration screen. It may:
  - set the emulator's options;
  - mount disk images;
  - show system information;
  - load programs and cartridges directly.
- The firmware runs nothing else.
