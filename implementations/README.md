# CoCo Zero implementations

Every known CoCo Zero: a board and the firmware that runs on it. Anything that
meets every requirement in [`spec/`](../spec/) belongs here.

|---|---|---|---|---|

## Adding one

Open an issue or a pull request with a row for the table: the board, the
firmware, a link to its source, and its license. Say how it meets each spec
page. See [CONTRIBUTING.md](../CONTRIBUTING.md).
